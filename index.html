Elliptic workbench

Given a minimal Weierstrass model of an elliptic curve over ℚ, the workbench assembles the refined Birch–Swinnerton-Dyer quotient in the rank-zero channel: L(E,1) by a smoothed Dirichlet series, the real period Ω by the arithmetic–geometric mean, the Tamagawa product and a torsion bound by local analysis and point counts, and from them an estimate of |Ш|. Provenance Every figure is engine-computed from the curve’s integer coefficients alone. LMFDB’s published values appear only as an oracle-after in the acceptance suite — never as an input to the pipeline.
Limits Rank 0, ε = +1, semistable, minimal models. |Ш| is an upper bound: the torsion is a gcd bound that enters the quotient squared, so an overshoot inflates the estimate. Exact only where the torsion bound is tight.
